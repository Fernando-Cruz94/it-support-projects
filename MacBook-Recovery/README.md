# 🧰 Project 1 – MacBook Pro Recovery with Apple ID

This project documents the recovery and macOS update of a MacBook Pro that was locked due to a forgotten password. I used the Apple ID Recovery feature and verified encryption through FileVault, ensuring the device remained secure throughout the process.

---

## 💻 Device Information

- **Model:** MacBook Pro Retina 15” (A1398)
- **Original OS:** macOS Big Sur
- **Owner Status:** Device unused for years; password forgotten
- **Security:** FileVault Encryption + Apple ID Protection

---

## 🔐 Recovery Process

### Step 1: Initial Diagnosis
- Found locked screen with the owner's name.
- Password forgotten. Message suggested password help.

### Step 2: Enter Recovery Mode
- Rebooted and pressed `Cmd + R` to access macOS Recovery.
- Connected the Mac to Wi-Fi to proceed with Apple ID verification.

### Step 3: Apple ID Verification
- Selected the user account and entered Apple ID.
- Verified with a 2FA code sent to the user’s iPhone.
- System unlocked successfully.
- Created a new password for the user.

> ✅ No use of Terminal or bypass tools — only secure, official recovery methods.

---

## 🔄 System Update

- Checked disk space via `About This Mac > Storage` (20+ GB free).
- Went to `System Preferences > Software Update`.
- Downloaded and installed macOS updates:
  - Safari upgrade
  - Security patches
  - System stability fixes

---

## ✅ Final Result

- The Mac is now **accessible, updated, and secure**.
- FileVault remains active.
- The owner regained control with a new password.

---

## 💡 Lessons Learned

- Apple provides guided recovery paths with Apple ID.
- Explained the process in clear language to a non-technical user.
- Practiced ethical and secure recovery techniques.
- Performed basic post-recovery system maintenance.
